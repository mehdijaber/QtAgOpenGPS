# Getting Started with QtAgOpenGPS

This section covers installation and initial setup for QtAgOpenGPS across different platforms.

## Installation Guides

- [Windows Installation](installation-windows.md) - Install Qt, build tools, and compile QtAgOpenGPS on Windows
- [Linux Installation](installation-linux.md) - Install dependencies and build on Linux systems
- [Android Installation](installation-android.md) - Build QtAgOpenGPS for Android devices
- [Android on Linux](android-linux.md) - Build Android version from Linux host

## Prerequisites

All platforms require:
- Qt 6.8 or newer
- CMake 3.22+ (3.27 recommended)
- C++17 compatible compiler
- OpenGL ES 2.0+ support

## Quick Start

1. Install Qt 6.8+ with Qt Creator
2. Clone the repository
3. Open CMakeLists.txt in Qt Creator
4. Configure and build
5. Run QtAgOpenGPS

For detailed platform-specific instructions, see the installation guides above.
